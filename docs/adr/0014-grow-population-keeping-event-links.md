# ADR-0014. 기준 집단은 사건 관계를 지키는 방식으로만 늘린다

## 배경

[ADR-0011](0011-expand-population-to-1000.md)의 1,000명 확장본은 사건 관계가 없어 kcalc로 계산할 수 없었다. 저장소 환자 461명으로 기준 집단을 사전 점검(`python -m medical audit`, k_req = 5)한 결과는 다음과 같다.

| 공개 | 1 ≤ k < 5 비율 |
| --- | --- |
| 도시 하나만 | 54.7% |
| 정확한 날짜 하나만 | 98.5% |
| 성별 + 도시 | 70.9% |
| 단서 4개까지 | 100% |

처음 위반에 도달하는 단서 수는 중앙값 2개였다.

## 결정

- 개발과 파일럿은 저장소 461명으로 한다.
- 본실험 전에 합성데이터 담당에게 Synthea로 같은 사건연결표 형식의 환자를 더 생성해 달라고 요청한다.
- 1,000명 확장본은 의료 본실험에 쓰지 않는다.
- 기준 집단을 줄여서 문제를 피하지 않는다.

## 근거

- 실제 병원 데이터는 이보다 훨씬 크다. 기준 집단을 줄이면 현실과 더 멀어진다.
- 사건 관계를 지켜야 [ADR-0012](0012-event-level-kcalc.md)의 계산이 성립한다.

## 검토한 대안

- 1,000명 확장본 사용: kcalc로 계산할 수 없다.
- 461명 그대로 본실험: 도시 · 날짜 하나로도 대부분 위반이라 갈래 간 차이가 드러나지 않는다.

## 결과와 영향

- 지금 규모에서는 Defender가 도시 · 날짜를 거의 항상 막아서 갈래 간 차이가 덜 드러난다. 결과 보고에 한계로 적는다.

## 남은 일

Synthea 추가 생성 요청과 생성본의 묶음 검사. 합성데이터 담당.
